# 验收对照 — #1539 海外社媒矩阵 AI 获客工作流样例

## 验收标准原文

> 提交可演示流程、输入素材及输出示例、账号授权与人工审核步骤、发布失败恢复和数据反馈说明，并列出运行成本口径。

## 逐条对照

| 验收要求 | 交付物 | 验证方式 | run_tests 断言 |
|---|---|---|---|
| 可演示流程 | `social_pipeline.py` + `demo.py` | 草稿→审核→模拟发布→反馈 | 1、12 |
| 输入素材及输出示例 | `examples/materials.json` + demo 输出 | 5 条脱敏素材加载 | 2、4 |
| 多平台/账号授权说明 | `workflow.accounts[].authorized` | facebook/instagram/tiktok + authorized 字段 | 3 |
| **人工审核步骤** | `moderate()` 门 | 未审核禁止发布、可驳回 | 5、6 |
| **发布失败恢复** | `publish(fail_once)` 重试 | 失败重试成功 | 7、8 |
| **数据反馈说明** | `feedback()` | 汇总成功/失败/尝试次数 | 9 |
| **成本口径** | `cost_model` dev/ops + USD | 分开 + 币种 | 10 |
| 反例 | 非法配置 | schema 拒绝 | 11 |
