# 实现说明 — #1539 海外社媒矩阵 AI 获客工作流样例

## 需求还原

外贸业务已有海外社媒账号/独立站/自有素材，希望减少人工发布负担。
本单要求一个**可演示**的获客工作流样例（$50），重点 Facebook、
多账号可扩展，优先自有素材、按计划每天 2-3 条草稿、保留人工监管。

**验收标准**：提交可演示流程、输入素材及输出示例、账号授权与人工审核
步骤、发布失败恢复和数据反馈说明，并列出运行成本口径。

## 设计

### 1. 配置模型（schema）

`schema/workflow.schema.json`：
- `platforms`：facebook/instagram/tiktok + accounts（含 `authorized`）
- `publish_plan`：daily_min/max、timezone、best_hours
- `moderation`：human_in_loop + steps
- `cost_model`：dev_cost_note / ops_cost_note / currency=USD

### 2. 流程（对应验收点）

```
素材库（脱敏）→ generate_drafts()（按计划 2-3 条/日）
→ moderate() 人工审核（未审核不能发布）
→ publish(simulate=True) 模拟发布（可 fail_once 重试）
→ feedback() 数据反馈（成功/失败/尝试次数）
→ cost_model 成本口径（开发/运营分离）
```

### 3. 关键安全边界

- **不碰真实账号**：默认 `simulate=True`；真实 API 需 external adapter
  与账号授权（`authorized=true`），不在样例范围。
- **人工审核门在前**：未审核草稿 `publish` 抛 `PipelineError`（测试 6）。
- **失败恢复**：`publish(fail_once=True)` 首次失败后自动重试，记录
  attempts（测试 8）。

### 4. 零依赖

纯标准库 json/os/re/sys/time，买家可直接运行 demo 复现。

## 与系列其他单的关系

复用 #1506/#1530 的"结果可复算"原则：所有输出（草稿数量、发布结果、
反馈聚合）从输入与配置逐条推出，无隐藏口径。人工审核门的设计与
#1531 非提案流程的审批门一脉相承。
